# Corbett Systems site branding update

This package contains the updated `index.html`, `style.css`, `favicon.svg`, and new branding assets.

## Deploy
Upload/replace these files in the root of your GitHub Pages repository:
- `index.html`
- `style.css`
- `favicon.svg`

Upload the new files from `assets/` into the repository's existing `assets/` folder.

Keep your existing `assets/corbett-systems-portfolio-banner.png` file: the HTML still references it for the portfolio/project visuals.

The page sections, navigation anchors, and main content structure have been preserved; the changes focus on the blue/teal/gold brand palette, header lockup, tagline, favicon, and subtle branded hero texture.
